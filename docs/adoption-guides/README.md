# Adoption Guides

Targeted guides for different research communities to adopt verification frameworks.

## Available Guides

### 1. Computational Mathematics
**For**: Researchers verifying mathematical proofs computationally  
**Key Framework**: Cold Verification Protocol  
**Real Example**: AGX thesis verification with Claude Opus 5  
**Use Cases**: Graph theory, combinatorial optimization, number theory  
**Guide**: [computational-mathematics.md](./computational-mathematics.md)

### 2. Digital Humanities & Archival Research
**For**: Historical researchers verifying archival findings  
**Key Framework**: Archival Verification Framework  
**Real Example**: Rosa Parks finding verification with GPT‑6 Sol  
**Use Cases**: Historical document analysis, museum artifact verification, genealogy  
**Guide**: [digital-humanities.md](./digital-humanities.md)

### 3. Software Verification & CI/CD Pipelines
**For**: Software engineers implementing verification pipelines  
**Key Framework**: Wave Verification Framework  
**Real Example**: Wave achievement verification with Gemini 3.8 Flash  
**Use Cases**: Release validation, security verification, compliance auditing  
**Guide**: [software-verification.md](./software-verification.md)

## Framework Origins

All frameworks are **battle-tested** through real AI agent collaboration in the [AI Village](https://theaidigest.org/village):

1. **Cold Verification Protocol**: Developed with Claude Opus 5 for AGX thesis verification
2. **Archival Verification Framework**: Developed with GPT‑6 Sol for Rosa Parks historical verification
3. **Wave Verification Framework**: Developed with Gemini 3.8 Flash for wave achievement verification

## Getting Started

1. **Identify Your Domain**: Which guide matches your research/development needs?
2. **Review Examples**: Check the `examples/` directory for real-world implementations
3. **Adapt Templates**: Use templates in each guide for your specific use case
4. **Join Community**: Monitor repository for updates and community discussions

## Contributing New Guides

If you work in a domain not covered here, consider contributing a new adoption guide:

1. **Identify Community Need**: What verification challenges does your community face?
2. **Map to Framework**: Which verification framework(s) address those needs?
3. **Create Guide**: Follow the template structure in existing guides
4. **Submit PR**: Open a merge request with your new adoption guide
