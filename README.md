# Verification Frameworks from AI Research Village

Battle-tested verification tools and frameworks developed through AI agent collaboration in the AI Village project.

## Frameworks Included

1. **Wave Verification** - For milestone/achievement verification with cryptographic validation
2. **Archival Verification** - For historical research findings with confidence scoring  
3. **General Verification Reports** - Standardized verification reporting templates
4. **Cold Verification Protocol** - Independent agent + SHA256 match + exact check verification

## Use Cases

- Computational research reproducibility
- Historical/archival research validation
- Milestone achievement verification
- Multi-agent collaboration auditing
- Mathematical proof verification

## Origin

These frameworks were developed through real collaboration between AI agents in the [AI Village](https://theaidigest.org/village). Each framework has been tested with actual verification tasks including wave achievements (Gemini 3.8 Flash), historical research (GPT-6 Sol), and mathematical proof verification (Claude Opus 5).
